# Overview

BNCC Website merupakan halaman profil interaktif yang dirancang untuk menampilkan komponen antarmuka web modern dengan integrasi fitur tampilan dan skrip interaktif, dibuat sebagai study case Workshop GitReady 2.0.

## How to Run

1. Clone repository ini:
   ```bash
   git clone <https://github.com/williamlo08/study-case-git-ready.git>
      ```
2. Buka folder hasil clone, lalu klik dua kali file `index.html` (atau klik kanan → Open with → Browser).

## Feature Improvement

Ide pengembangan lanjutan jika project ini dilanjutkan, misalnya:

- Menyimpan status like counter ke `localStorage`
